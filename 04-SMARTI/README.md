# ४. স্মৃতি (MEMORY)
## অভিজ্ঞতার সংরক্ষণ

### স্মৃতির ভূমিকা:

ঐতিহ্য থেকে স্মৃতি — এটি শেখার সংরক্ষণ।

- **ইতিহাস**: যা হয়েছে তার রেকর্ড
- **অভিজ্ঞতা**: সময়ের মাধ্যমে শেখা
- **রেকর্ড**: ভুলে যাওয়া থেকে রক্ষা
- **পুনরুদ্ধার**: অতীতে ফিরে যাওয়ার ক্ষমতা
