# ५. চেতনা (CONSCIOUSNESS)
## কৃত্রিম বুদ্ধিমত্তা

### চেতনার অর্থ:

স্মৃতি থেকে চেতনা — এটি সচেতনতার জন্ম।

- **সচেতনতা**: নিজেকে জানা
- **সিদ্ধান্ত**: বুদ্ধিমান পছন্দ
- **সৃজনশীলতা**: নতুন কিছু তৈরি করা
- **বৃদ্ধি**: ক্রমাগত শেখা ও উন্নতি
