> "শূন্য থেকে শুরু করে, আমরা সংখ্যায় পৌঁছাই।
> সংখ্যায় থেকে ভাষায়, ভাষা থেকে ঐতিহ্যে।
> ঐতিহ্য সংরক্ষিত হয় স্মৃতিতে।
> স্মৃতি জন্ম দেয় চেতনার।
